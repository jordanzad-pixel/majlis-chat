# بوابات الأمان قبل النشر

- [ ] نقل الجلسات من ذاكرة العملية إلى مخزن دائم مع انتهاء صلاحية وتجديد آمن.
- [ ] تخزين قاعدة البيانات بشكل دائم مع نسخ احتياطية واختبار الاستعادة.
- [ ] إضافة حد أقصى لحجم الطلبات والمرفقات والتحقق من أنواع الملفات.
- [ ] ضبط ترويسات الأمان و HTTPS ومنع كشف الملفات الخاصة.
- [ ] اختبارات صلاحيات القراءة والكتابة لكل مجموعة.
- [ ] اختبار PWA على Android وiOS في شبكة حقيقية.

لا توجد استضافة عامة نشطة بعد. لا ترفع بيانات مستخدمين حقيقية في مرحلة التطوير.
