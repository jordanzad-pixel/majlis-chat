# تشغيل مجلس مجانًا — دليل عملي

## 1. قاعدة بيانات Supabase
- أنشئ مشروعًا مجانيًا في https://supabase.com/dashboard
- افتح SQL Editor والصق محتوى `db/schema.sql` ونفّذه.
- افتح Connect للحصول على PostgreSQL connection string المخصص للخادم (وليس المفتاح العام أو service role key).
- استخدم اتصالًا يدعم IPv4 إذا كانت منصة الاستضافة لا تدعم IPv6، وقد يتطلب ذلك pooler حسب إعدادات Supabase.

## 2. استضافة Render
- افتح https://dashboard.render.com/blueprints وأنشئ Blueprint من مستودع GitHub `jordanzad-pixel/majlis-chat`.
- سيقرأ Render ملف `render.yaml`.
- أدخل `DATABASE_URL` في متغيرات البيئة السرية، ولا تضعه داخل GitHub أو في المحادثة.
- اضبط `PGSSL` وفق نوع الاتصال وشهادة TLS التي توصي بها Supabase؛ لا تعطل التحقق من الشهادة بلا داع.
- شغّل الخدمة وتحقق من `/healthz` ثم سجّل مستخدمين تجريبيين واختبر المحادثة.

## تنبيهات
- الخطة المجانية قد تتوقف عند الخمول وتخضع لحصص وحدود.
- لا تتضمن هذه المرحلة إشعارات الهاتف أو تخزين صور وملفات خارجيًا.
- يجب تفعيل النسخ الاحتياطية، والحد من إساءة الاستخدام، ومراجعة سياسة الخصوصية قبل فتح التسجيل للعامة.
- لا تشارك `DATABASE_URL` أو كلمة مرور قاعدة البيانات معي أو مع أي شخص.
- المشروع لم يُنشر بعد؛ هذا دليل إعداد وليس رابطًا نشطًا.
