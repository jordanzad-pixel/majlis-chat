# تشغيل مجلس كـ PWA — خطة النشر

> **الحالة:** نسخة تطويرية؛ لم يتم نشر التطبيق بعد، ولا ينبغي إدخال بيانات مستخدمين حقيقيين قبل الاختبارات الأمنية.

## المسار المجاني
- استضافة واجهة PWA على خدمة HTTPS مجانية.
- استضافة API مع تخزين دائم لقاعدة البيانات، ضمن حدود الخطة المجانية.
- لا حاجة لمتاجر التطبيقات؛ التثبيت من المتصفح.

## قبل النشر
1. منع تعيين مدير تلقائيًا لأول مستخدم.
2. إزالة أي حسابات تجريبية من قاعدة البيانات المنشورة.
3. تفعيل نسخ احتياطية وتخزين دائم.
4. حماية الجلسات، وتحديد معدل الطلبات، واختبار صلاحيات المجموعات.
5. ضبط HTTPS وسياسات الخصوصية والبلاغات.

## ملاحظة
لا ترفع ملفات `.env` أو `data/db.json` أو أي مفاتيح API إلى GitHub. لا يُعد هذا الملف نشرًا فعليًا للتطبيق.
