# اختيار الاستضافة المجانية — 2026-10-08

## القرار
- **Render Free Web Service** لاستضافة Node.js وHTTPS خلال التجارب.
- **Supabase Free PostgreSQL** لتخزين الحسابات والمجموعات والرسائل لاحقًا.

## لماذا لا ننشر الآن؟
تطبيق GitHub الحالي يخزن البيانات في ملف JSON محلي. قرص Render المجاني مؤقت وتُفقد تغييرات الملفات عند إعادة التشغيل أو توقف الخدمة أو إعادة النشر. لا يجوز نشر تطبيق محادثة حقيقي بهذا التخزين.

قاعدة Render Postgres المجانية تنتهي بعد 30 يومًا، لذلك لا نعتمدها لتخزين محادثات دائمة. قاعدة Supabase المجانية تتيح 500 MB ضمن حدود الخدمة وقد تتوقف عند الخمول؛ ليست بديلًا عن النسخ الاحتياطية.

## متطلبات التنفيذ
1. تحويل واجهة التخزين من JSON إلى PostgreSQL، مع عمليات ذرية لعضوية المجموعات والرسائل والجلسات.
2. اختبار نقل البيانات والنسخ الاحتياطية.
3. نشر Render Free مع ربط متغير DATABASE_URL بسرّ بيئة، دون رفعه إلى GitHub.
4. إجراء اختبارات API وPWA عبر HTTPS ثم فتح التسجيل للمستخدمين.

## الأمان
أضفنا حارس تشغيل يمنع NODE_ENV=production مع التخزين المحلي JSON افتراضيًا. الاستثناء MAJLIS_ALLOW_JSON_PRODUCTION=true مخصص فقط لبيئة تملك قرصًا دائمًا وتم اختبار نسخها الاحتياطية، ولا يُستخدم على Render Free.
