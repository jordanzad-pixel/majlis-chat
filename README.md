# مجلس | Majlis

نسخة ويب أولية للمحادثات الجماعية باللغة العربية. هذا المستودع يحتوي الآن على خادم API وواجهة PWA أولية قابلة للتشغيل محليًا، لكنها **ليست النسخة v17 الكاملة** وليست جاهزة للنشر العام أو بيانات مستخدمين حقيقية.

## التشغيل المحلي

```bash
npm test
npm start
```

ثم افتح http://localhost:3000. لا تحتاج إلى تثبيت حزم خارجية لتشغيل الخادم. يتطلب Node.js 20 أو أحدث.

## الموجود الآن
- تسجيل حساب ودخول بكلمة مرور مجزأة باستخدام scrypt.
- إنشاء مجموعات خاصة وإضافة عضو مسجل بالبريد.
- إرسال وقراءة رسائل نصية، مع تحديث تلقائي كل 3 ثوانٍ.
- واجهة عربية متجاوبة، وملف PWA وService Worker.
- اختبارات تكامل أولية في GitHub Actions.

## قيود قبل النشر
- تخزين JSON محلي يحتاج قرصًا دائمًا ونسخًا احتياطية.
- لا توجد بعد إدارة بلاغات أو رفع وسائط في **هذه النسخة المنشورة على GitHub**.
- يجب اختبار الصلاحيات ومعدلات الطلبات والتعافي من الأعطال قبل فتح التسجيل للعامة.
- مستودع GitHub عام؛ لا ترفع أسرارًا أو بيانات مستخدمين.

## الخطوة القادمة
تشغيل CI ثم إعداد استضافة HTTPS وتخزين دائم بعد اجتياز اختبارات الأمن.
