# مجلس | Majlis Chat

تطبيق عربي للمحادثات الجماعية، مخطط ليعمل كتطبيق ويب قابل للتثبيت (PWA) على Android وiPhone والكمبيوتر دون متاجر.

## حالة المشروع
- الإصدارات التجريبية السابقة محفوظة خارج GitHub، ولم تُرفع شفرتها بعد إلى هذا المستودع.
- هذا المستودع مخصص لإدارة الكود والإصدارات القادمة.
- **ليس منشورًا للعامة كخدمة محادثة، ولا يصلح حاليًا لتخزين بيانات مستخدمين حقيقيين.**

## الخطة
1. استيراد شفرة PWA بعد مراجعة الأسرار والحسابات التجريبية.
2. نقل البيانات إلى PostgreSQL وتخزين الوسائط إلى خدمة ملفات.
3. تفعيل HTTPS والمصادقة وإدارة الجلسات والنسخ الاحتياطي.
4. اختبار صلاحيات المجموعات والبلاغات قبل النشر.
5. نشر نسخة مجانية ضمن حدود الخدمة المختارة.

## الأمان
لا ترفع ملفات `.env` أو قواعد البيانات المحلية أو كلمات المرور أو رموز الوصول إلى هذا المستودع. مستودع GitHub **عام حاليًا**، ويمكن تغيير ظهوره من Settings → General → Danger Zone → Change repository visibility.
